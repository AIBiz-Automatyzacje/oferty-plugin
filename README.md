# Plugin Traferto dla Claude Code

Skill i konfiguracja connectora MCP dla [Traferto](https://app.traferto.pl) — narzędzia, które zamienia ofertę B2B w osobną stronę dla klienta i pokazuje, które jej części przeczytał.

**Status: w przygotowaniu.** Repozytorium jest publiczne, ale plugin nie został jeszcze opublikowany — komenda instalacyjna z panelu Traferto zadziała po pierwszym wydaniu.

Docelowa instalacja w Claude Code:

```
/plugin marketplace add AIBiz-Automatyzacje/oferty-plugin
```

Plugin niesie adres serwera MCP, więc po instalacji zostaje tylko wklejenie tokenu z ustawień konta.

Wydawca: Akademia Automatyzacji.
