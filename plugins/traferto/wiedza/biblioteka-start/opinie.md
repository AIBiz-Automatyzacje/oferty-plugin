# Opinie klientów

> Cytaty dosłowne, z podpisem, branżą i datą. Skill `oferta` wstawia je do `referencje` bez
> zmian, dobierając po branży i problemie. Opinia bez zgody klienta na cytowanie nie wchodzi
> do oferty — pole „zgoda" jest po to, żeby o tym pamiętać. Skill nigdy nie zmienia treści
> cytatu; nowy wpis tylko po zatwierdzeniu handlowca.

Format wpisu:

```
### <imię i nazwisko, stanowisko, firma>
- **Branża:** <branża> · **Problem:** <problem, którego dotyczyła współpraca>
- **Data:** <RRRR-MM>
- **Zgoda na cytowanie:** tak / nie / do potwierdzenia
- **Cytat:** „<dosłownie>"
- **Kontekst:** <jedno zdanie: z jakiej realizacji, co poprzedzało>
```
